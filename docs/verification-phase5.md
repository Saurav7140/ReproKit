## Implemented scope

- Optional Supabase email/password signup/sign-in, confirmation/resend, PKCE recovery and session refresh/sign-out.
- Single-owner projects, paginated report lists, persisted open/investigating/resolved status, explicit reviewed local-report upload, and the existing investigation viewer for fetched copies.
- Actual SQL migration with RLS, project/owner integrity, column-limited status writes, service-only ingestion/delete/cleanup RPCs and a private recordings bucket. Clients cannot directly sign/read/write/delete recordings.
- Shared client/server bounded schema validation, canonical hashing, 5 MiB cap, server-derived object paths, duplicate-safe uploads and conflict rejection, 20 attempts/hour, 25 projects and 100 reports/account.
- Pending/ready/deleting lifecycle, 15-minute leases, Storage-before-metadata deletion and recoverable incomplete work. Owner read authorization produces a 60-second signed URL; reads stop after 30 days. The installed Vault/Cron/pg_net schedule calls batches of 50 every 15 minutes.
- Public-key build guard, separate browser/server/test configuration examples, setup/runbook, offline live-script self-check and opt-in configured-service acceptance script.
