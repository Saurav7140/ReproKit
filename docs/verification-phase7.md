## Run, limits and remaining work

Start `npm.cmd run dev:sdk` (5176) and `npm.cmd run dev` (5173). Use **Report a problem → consent → Start recording**, reproduce the synthetic failure, **Stop and review → Save details → Submit report**. Sign into the dashboard, select **Website SDK sample**, refresh and open it. The extension is not required. [Full run/test checklist, host API and fresh-project setup](website-sdk.md).

Public keys/origins are forgeable outside browsers; this is write-only intake, not visitor authentication or proof of consent. Ten attempts/hour, 20 report slots/project, 5 MiB/report and existing owner caps bound accepted uploads, not function invocation costs or distributed denial of service. Attackers can exhaust quota or submit fabricated reports. Upstream bot/abuse protection is required before broad exposure. Already reserved work may finish after disable/rotation. No CAPTCHA/WAF, load testing, comprehensive cross-browser certification, package publication or Phase 8 hardening is claimed. Client errors use available Resource Timing metadata; same-page reload loses unsaved reports. [Security model](website-sdk.md#public-ingestion-security-model).
